# Go2 VLN input interface: `go2-vln-obs-v1`

Package `go2_perception.vln` (new in Phase 5D). Model-agnostic, read-only, offline-replayable. It
does not plan, command or move the robot. Code: `src/go2_perception/vln/`; tests:
`tests/test_vln_interface.py` (30 tests); config: `configs/go2_vln_sensors.yaml`.

## Conventions
- Units: metres, seconds, radians; pixels for K. Images uint8 **RGB** H×W×3.
- Frames: `base_link` x forward, y left, z up (floor at z ≈ −0.33 m standing); `odom` same axes at
  the odometry origin; camera optical frame x right, y down, z forward.
- Transforms: `T_target_source`, `p_target = T @ p_source` (column vectors, 4×4, row-major).
- Every timestamp is a `Stamp(t, clock, semantics, uncertainty_s)`. Clocks: `go2_robot` (resets each
  boot, see `clock_epoch`) and `host_receipt`. Semantics: `exposure`, `exposure_estimated`,
  `host_receipt`, `scan_midpoint`, `message_stamp`.
- `None` means unknown. A missing pose is never identity; an absent LiDAR return is never free space.
  3D object boxes are not part of the interface and are never free-space evidence.

## Fields
### A. `VisualObservation` (may be `None`)
| Field | Type | Notes |
|---|---|---|
| `image` | uint8 (720, 1280, 3) RGB | raw, distorted; `rectified=False` |
| `frame_id` | str | `go2_front_camera_unrectified` until calibrated |
| `stamp_host` | Stamp | first RTP packet receipt, `host_receipt` clock |
| `stamp_robot` | Stamp or None | `exposure_estimated` in `go2_robot`: host − offset − 48 ms; σ ≈ 16 ms |
| `intrinsics_status` | `unknown` / `synthetic` / `measured` | `measured` when replayed with `calibration=configs/go2_front_camera_calibration.yaml` |
| `K`, `D`, `distortion_model`, `intrinsics_size` | arrays / str / (w, h) | fisheye_equidistant, (1280, 720); all `None` without a calibration file |
| `history` | list[VisualObservation] | oldest first, `observation(k, history=n)` |

### B. `GeometricObservation` (may be `None`)
| Field | Type | Notes |
|---|---|---|
| `frame_id`, `stamp` | `base_link`, scan midpoint (robot clock) | of the reference `cloud_base` scan |
| `points` | float32 (N, 3) | **0.5 s** obstacle window, ego-motion compensated by odometry (~11 k points) |
| `display_points`, `display_window_s` | float32 (M, 3), 1.0 | **1.0 s** display window (user choice, 2026-11-11) |
| `grid` | int8 (100, 100), 0.1 m, x −3…7, y −5…5 | −1 unknown, 0 floor seen, 1 occupied (0.1–1.2 m above floor) |
| `elevation_max` | float32 like `grid` | highest return, NaN unobserved (2.5D) |
| `sector_range` | float (72,) | nearest obstacle per 5° sector CCW from +x, NaN = no return (unknown) |
| `sector_clear_to` | float (72,) | farthest floor return before that obstacle, NaN = no evidence |
| `blind_radius_m` | 0.30 | `cloud_base` has no points inside; always unknown |
| `projected_depth` | float32 (H, W) or None | needs intrinsics **and** `T_base_camera`; `None` until extrinsics are measured |

FREE means "floor was seen and nothing in the obstacle band", not "traversable": obstacles lower than
10 cm above the floor, glass, black or very thin objects may be missed.

### C. `RobotState`
`stamp` (robot clock), `T_odom_base` (4×4 or None), `linear_velocity`, `angular_velocity`,
`velocity_frame` = `base_link (nav_msgs child-frame convention; unverified on Go2)`.

### Envelope `Go2VLNObservation`
`schema_version`, `instruction`, `clock_epoch` (`go2_boot:host_minus_robot=…`), `host_minus_robot_s`,
`calibration` (statuses, camera latency and its source), `warnings`.

## Use
```python
from go2_perception.vln import validate, save, load
from go2_perception.vln.replay import Go2RecordingReplay
from go2_perception.vln.tensors import resize, to_tensor, stack_history

replay = Go2RecordingReplay("data/recordings/p5d_static_02",
                            calibration="configs/go2_front_camera_calibration.yaml")  # measured intrinsics
obs = replay.observation(200, history=2, instruction="Go to the kitchen")
assert validate(obs) == []                                          # list of issues; strict=True raises
small, K_small, info = resize(obs.visual.image, (448, 448), None)   # pass intrinsics when known
x = to_tensor(small)                                                # float32 3x448x448, ImageNet-normalised
save(obs, "obs.vlnobs.npz"); obs2 = load("obs.vlnobs.npz")          # npz, no pickle
```
Demo: `scripts/phase5d_vln_replay_demo.py --recording … | --synthetic` writes the npz, a rendering and
a field report. Synthetic fixture: `tests/fixtures/vln/synthetic_recording` (160×120, 12 scans, box
+ wall + floor, synthetic calibration; regenerated byte-identically by `vln.synthetic.write_recording`).

## Validation (`validate`)
Checks schema version; image dtype/shape; named frames; finite timestamps with known semantics; the
host stamp is host receipt; K/D only with known intrinsics and matching `intrinsics_size`; raw images
need a distortion model; history strictly older; finite (N, 3) points; grid values in {−1, 0, 1};
shapes of elevation and sector arrays; projected depth only with measured (or explicitly allowed
synthetic) extrinsics and matching image size; rigid `T_odom_base`; velocities need a frame;
**clock-domain mismatch** (visual without a robot-clock stamp, or differing clocks) and skew between
visual, geometry and robot state above `max_skew_s` (0.15 s default).

## Versioning
Additive optional fields keep `go2-vln-obs-v1`; any renamed, removed or re-meant field needs
`go2-vln-obs-v2`. `load` refuses unknown versions.
